# Укради ядро: Лаборатория мутантов

HTML5 canvas игра. Управление: WASD / стрелки или касание/перетаскивание по экрану. Подбирайте ядра, возвращайтесь на базу, нажимайте «Сдать ядра», покупайте улучшения.

## Запуск
Откройте index.html в браузере. Для проверки через локальный сервер: `python -m http.server 8000` и http://localhost:8000.

## Яндекс Игры
Заархивируйте содержимое папки так, чтобы index.html находился в корне архива, и загрузите в консоль разработчика. Используется `/sdk.js`, рекомендуемый путь для архивного размещения. Реклама и SDK полноценно проверяются только в окружении платформы. Для GitHub Pages вместо `/sdk.js` понадобится абсолютный URL SDK.

## Известные ограничения
Первая играбельная версия, без серверных сохранений, внутриигровых покупок и полноценной системы врагов. Локальный прогресс хранится в localStorage.
