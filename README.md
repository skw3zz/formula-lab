# Формула LAB

Научный калькулятор на русском языке: **21 инструмент** по математике, физике и химии. Адаптивный интерфейс для телефона и ПК, шесть цветовых тем, подсказки ввода и короткий урок под каждым калькулятором.

## Возможности

- Математика: точные дроби, квадраты и кубы, произвольные степени и корни, выражения, векторы, матрицы, квадратные уравнения, комплексные числа, статистика, численные производные и интегралы.
- Физика: кинематика, сила и энергия, электрические цепи, идеальный газ, теплота, волны и фотоны.
- Химия: молярная масса, баланс реакций, количество вещества, растворы, pH, стехиометрия.
- Каждый урок объясняет обозначения, показывает три шага решения и содержит примеры, которые заполняют форму одним нажатием.
- В выражениях поддерживаются `sqrt(81)`, `cbrt(-27)`, `5^3`, а также `√(81)`, `∛(-27)`, `5³`. Обычная арифметика работает без использования корней.

## Запуск

Нужен Node.js 20.6 или новее. Установка сторонних пакетов не требуется.

```sh
npm start
```

Откройте http://127.0.0.1:5173.

```sh
npm test
npm run build
```

Первая команда запускает тесты, вторая собирает самостоятельный Cloudflare Worker в `dist/server/index.js`. Сборка не требует API-ключа.

## Структура кода

| Файл | Назначение |
| --- | --- |
| `dist/index.html` | Разметка калькуляторов, уроков, диалога и выбора темы |
| `dist/styles.css` | Общие стили, адаптивные размеры, шесть палитр |
| `dist/engine.js` | Независимые математические и химические вычисления |
| `dist/catalog.js` | Инструменты, поля, формулы и функции расчёта |
| `dist/lessons.js` | Объяснения и исполняемые примеры всех инструментов |
| `dist/app.js` | Навигация, формы, уроки, кнопки степеней и корней |
| `dist/themes.js` | Галерея тем и сохранение выбора |
| `dist/chat.js` | Подготовленный интерфейс ИИ-помощника |
| `server/chat-api.js` | Серверный вызов OpenAI, проверка ввода и обработка ошибок |
| `server.js` | Локальный сервер |
| `build.mjs` | Сборка Worker с публичными ресурсами |
| `tests/` | Проверки вычислений, учебных примеров и API-контракта |

Чтобы добавить калькулятор, создайте объект в `tools` в `catalog.js`: `id`, `subject`, `name`, `fields` и `calculate(values)`. Функция возвращает `{ value, details }` и бросает `Error` с понятным сообщением при ошибке ввода. Затем добавьте урок с тем же `id` в `lessons.js`.

## Точность и ограничения

Дроби и коэффициенты реакций используют BigInt и точную рациональную арифметику. Остальные расчёты используют JavaScript Number. Производные и интегралы приближённые: интеграл вычисляется формулой Симпсона на 2000 интервалах, функция должна быть гладкой на всём отрезке. Атомные массы округлены; для нестабильных элементов используются массовые числа.

Баланс реакции сохраняет атомы, но не предсказывает продукты или возможность протекания реакции. Ионные уравнения не поддерживаются. Ограничения физических моделей объясняются рядом с соответствующими формулами.

## ИИ: временно скрыт до настройки

По просьбе владельца неподключённый чат полностью скрыт. Если `/api/chat/status` сообщает, что серверный ключ настроен, кнопка чата появляется после перезагрузки. Без ключа нет имитации ответов.

Подключение подготовлено для OpenAI Responses API. По умолчанию используется `gpt-4.1-mini`; модель можно изменить серверной переменной `OPENAI_MODEL`. Для работы потребуется действующий `OPENAI_API_KEY` и доступ к API. Ключ нельзя помещать в `dist`, HTML, JavaScript браузера или GitHub.

Для локальной настройки служит `.env.example`. Секрет хранится только в игнорируемом `.env`; запуск с ним: `node --env-file=.env server.js`. На хостинге ключ задаётся серверным секретом. Текущая публикация приватная. До открытия ИИ для широкой аудитории потребуются аутентификация и устойчивые квоты расходов на пользователя.

Чат передаёт модельному провайдеру последние сообщения, предпочтения и, если включён переключатель, контекст калькулятора. Адаптация основана на истории и выбранном уровне, а не на обучении весов модели. История хранится в sessionStorage, профиль — в localStorage. `store: false` отключает сохранение объекта Responses, но не обещает отсутствия иных журналов у провайдера. Тесты API используют тестовый транспорт и не подтверждают доступ к живой модели.

Документация API: https://developers.openai.com/api/docs/guides/text

## Приватность и оформление

Обычные вычисления выполняются в браузере без отправки исходных данных на сервер. Выбор темы сохраняется локально. Manrope загружается из Google Fonts; при недоступности сети используется системный шрифт.

Тёмные темы: чёрный с оранжевым, голубым или белым. Светлые: белый с оранжевым, чёрным или голубым. На телефоне навигация переносится наверх, список инструментов прокручивается горизонтально, форма и результат располагаются друг под другом.
